# QalaHub AI — roadmap

## Пилот (Астана)
- [x] Независимый репозиторий и документация.
- [x] Чат-интерфейс с выбором города и быстрыми сценариями (ветка MVP).
- [x] Серверный доступ к Responses API с живым веб-поиском (ветка MVP).
- [ ] Подключить API-ключ и закрытый тестовый деплой на Vercel.
- [ ] Проверить свежесть и полноту источников: афиша, еда, досуг, бытовые проблемы.
- [ ] Добавить устойчивые городские каталоги и права на использование данных.
- [ ] Учёт реальной себестоимости запроса, квоты, распределённые ограничения частоты, мониторинг ошибок.
- [ ] Протестировать на реальных сценариях жителей Астаны, собрать обратную связь.

- [x] Передавать выбранный город и страну KZ в географические настройки веб-поиска.
- [x] Показывать предупреждение, когда ИИ не вернул проверяемые URL-источники.
- [x] Добавить кликабельные аннотации источников и план ручного тестирования Астаны.

## Следующий этап
- [ ] Отдельные инструменты для событий, заведений, маршрутов и бытовых услуг.
- [ ] Проверенные первоисточники и отметки о дате обновления.
- [ ] Учёт пользователей, настройки приватности, казахский язык.
- [ ] Интеграция с Мир Услуг 2 через отдельный API, только с подтверждением заявки.
- [ ] Голосовой интерфейс, затем навык Алисы при соблюдении ограничений платформы.
- [ ] База городских данных и worker для обновления (PostgreSQL + Redis).
- [ ] Алматы и другие города Казахстана.

Нельзя обещать реальное бронирование, оплату, свободные столики и доступных мастеров до подтверждённых интеграций.
