# QalaHub AI — roadmap

## Пилот (Астана)
- [x] Независимый репозиторий и документация.
- [x] Чат-интерфейс с выбором города и быстрыми сценариями (ветка MVP).
- [x] Серверный доступ к Responses API с живым веб-поиском (ветка MVP).
- [x] Закрытый тестовый деплой на Vercel с серверными переменными (успешная production-сборка; ответы требуют ручной проверки).
- [ ] Проверить свежесть и полноту источников: афиша, еда, досуг, бытовые проблемы.
- [ ] Добавить устойчивые городские каталоги и права на использование данных.
- [ ] Учёт реальной себестоимости запроса, квоты, распределённые ограничения частоты, мониторинг ошибок.
- [ ] Протестировать на реальных сценариях жителей Астаны, собрать обратную связь.

- [x] Передавать выбранный город и страну KZ в географические настройки веб-поиска.
- [x] Показывать предупреждение, когда ИИ не вернул проверяемые URL-источники.
- [x] Добавить кликабельные аннотации источников и план ручного тестирования Астаны.

- [x] Отдельная фильтрация ошибочных географических рекомендаций и источников вместо отклонения всего ответа.
- [x] Диагностика источников, полученных через веб-поиск (без объявления их проверенными адресами).

- [x] Единый реестр населённых пунктов пилота: ID, альтернативные названия, часовой пояс и статус покрытия.
- [x] Универсальные контракты мест и событий с привязкой к cityId.
- [ ] Подключить полный официальный справочник населённых пунктов Казахстана.
- [x] Первоначальные 22 города перенесены в БД; API списка городов читает БД при подключении.
- [ ] Перевести селектор сайта и проверку городов на динамический справочник БД, включая населённые пункты.
- [ ] Подключить лицензированных поставщиков событий и мест.

- [x] Отдельная база Neon `qalahub-ai`, таблицы созданы 30.10.2026.
- [x] SQL-миграция схемы `city`, `city_provider`, `city_place`, `city_event` с ограничениями `cityId`.
- [x] Подготовлены read-only API `/api/cities`, `/api/places`, `/api/events` и тесты фильтров.
- [x] По разрешению применена миграция, настроен DATABASE_URL (production) и загружены 22 города.
- [x] OpenStreetMap-поиск кафе, ресторанов и культурных мест по географическому центру города (закрытый пилот, ограничение и кэш 6 ч).
- [ ] Подключить источники мероприятий с датами, площадками и ссылками.

- [x] Погодные ответы нормализуются в градусы Цельсия; добавлена кнопка очистки диалога с отменой запроса.

## Следующий этап
- [ ] Отдельные инструменты для событий, заведений, маршрутов и бытовых услуг.
- [ ] Проверенные первоисточники и отметки о дате обновления.
- [ ] Учёт пользователей, настройки приватности, казахский язык.
- [ ] Интеграция с Мир Услуг 2 через отдельный API, только с подтверждением заявки.
- [ ] Голосовой интерфейс, затем навык Алисы при соблюдении ограничений платформы.
- [ ] База городских данных и worker для обновления (PostgreSQL + Redis).
- [ ] Алматы и другие города Казахстана.

Нельзя обещать реальное бронирование, оплату, свободные столики и доступных мастеров до подтверждённых интеграций.
