# OpenStreetMap: первый источник реальных мест

**Дата: 30.10.2026.** Адаптер для кафе/ресторанов и музеев/достопримечательностей. Не является афишей.

## API и ограничения

- POST /api/discover/places с JSON полями city, category (`food` или `culture`) и accessCode.
- Поиск строго по выбранному городу. Координаты центра загружаются только из базы Neon, пользователь не передаёт произвольные координаты или код Overpass.
- Открытый Overpass `overpass-api.de`: радиус 2,7 км для заведений, 3,8 км для культурных мест; максимум 100 объектов на запрос, до 14 показаны пользователю.
- Промежуточный серверный кэш Next.js по городу и категории на 6 часов. Кэш уменьшает нагрузку, но не заменяет распределённый rate limit при переходе к открытому продукту.
- Результат показывает только имя, адрес при наличии, координаты, примерное расстояние от центра и ссылку на исходный объект OpenStreetMap.
- Источник и лицензия: © OpenStreetMap contributors, ODbL. Сведения о ценах, часах работы, рейтингах и доступности не подтверждены.
- Секретный код пилота обязателен. Нет фоново запускаемых массовых запросов, импорта в БД или копирования защищённых данных.

## География

Проверенные центры из GeoNames добавлены в таблицу `city` для Астаны, Алматы, Шымкента и Павлодара. Это только первый запуск; дополнительные города включаются через координаты в БД **без изменения программного кода**. Пока координат нет, API честно возвращает сообщение, что геопоиск недоступен.

Поиск по радиусу не совпадает с административной границей города и может не покрывать удалённые районы. На следующем этапе необходимо работать с географическими границами и полноценным индексом мест.

## Проверка после деплоя

1. Ввести код пилота и нажать «Кафе и рестораны» или «Музеи и места». Проверить ссылки OpenStreetMap.
2. Проверить запросы для Астаны, Алматы, Шымкента и Павлодара.
3. Проверить неподключённый город: честная ошибка вместо информации другого города.
4. Проверить сохранение контекста чата и отмену поиска кнопкой «Очистить».
5. Сверить расходы/ошибки Overpass и новые Vercel runtime logs.

Публичный Overpass не гарантирует доступность и не предназначен для больших коммерческих нагрузок. Перед масштабированием выбрать собственный OSM-экстракт или коммерческий лицензированный каталог.
