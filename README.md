# QalaHub AI

**Городской ИИ-помощник для Казахстана.** Пилот: Астана. Архитектура допускает подключение других городов без отдельного приложения.

Сценарии: куда сходить, что происходит в городе, где поесть, досуг с детьми, бытовые проблемы, поиск услуг. QalaHub AI помогает найти проверяемые варианты и подготовить действия; не выдумывает мероприятия, цены, наличие мест или успешные бронирования.

## MVP

1. Веб-интерфейс с выбором города (Астана по умолчанию).
2. Диалог с ИИ и **актуальным веб-поиском**, ссылки на первоисточники.
3. Тематические быстрые запросы: афиша, еда, досуг, бытовые задачи.
4. Корректные ограничения: никакого автоматического бронирования, оплаты или отправки заявок без подтверждения.
5. Серверное хранение ключа ИИ, ограничение размера запросов и таймауты.

## Архитектура (поэтапно)

- `apps/web` — Next.js (первый MVP и серверный AI endpoint).
- `apps/api` — отдельный API для пользователей, источников и действий (следующий этап).
- `apps/worker` — обновление городской базы и фоновые задания (следующий этап).
- `packages/ai-agent`, `packages/city-data`, `packages/integrations`, `packages/database` — модули по мере появления реального функционала.

Связи с Мир Услуг 2, Notify KZ и Алисой планируются как внешние интеграции, а не как зависимость ядра.

## Запуск MVP

См. `apps/web/README.md` после добавления веб-приложения.

**Важно:** без `OPENAI_API_KEY` живой ИИ-поиск недоступен. Никаких имитаций результатов и ложных цен.

## Принципы

- Русский на старте, казахский в дорожной карте.
- Город и часовой пояс задаются явно.
- События и часы работы проверяются по актуальным источникам.
- Рекламные рекомендации отмечаются и не подмешиваются скрытно.
- Персональные данные собираются только для нужных пользовательских действий.
